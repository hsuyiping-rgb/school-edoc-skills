# 規格補正建議表的寫法

估價單只要有品項缺規格，就要另出一份「採購品項規格補正建議表」。

這份文件的定位很重要：**它不是第二份問題清單，而是可以直接貼進需求說明書的規格稿。** 承辦人拿到手應該能複製貼上，而不是還要自己想一遍。所以每一條都要寫成規格的樣子（「16GB DDR5 以上」），不要寫成評論的樣子（「記憶體規格不足」）。

## 文件結構

```
壹、問題確認          — 現行估價單哪裡不足、違反什麼、會造成什麼後果
貳、（重點品項）規格表 — 使用者最在意或問題最嚴重的那一項，兩欄式完整規格
參、其餘品項規格補正   — 逐項條列應補列的規格內容
肆、共通條款          — 適用全部品項的要求，放開頭統一載明，免得逐項重複
伍、承辦人須先行確認事項 — 必須現場丈量或問專業人員才能填的東西
```

## 三個原則

**寫成最低要求，保留同等品空間**
規格是門檻不是指定。用「以上」「≧」「或同等」的寫法，並在共通條款載明廠商得提出同等或優於本規格之產品。這樣既擋掉劣質品，又不違反 `採購法 §26 III`。

**替代品名，不是描述品名**
遇到型錄品名（「◯◯套組」「◯◯系列 12 件」「X 組」），不要試圖去查那是什麼再照抄。改寫成功能描述加填空：

> 「X 套組」為特定型錄編號，應改以功能描述：壁掛式操作板，含轉盤、齒輪、滑軌、軌道球等操作元件 ___ 種以上。載明總尺寸、板材、固定方式；所有可動件須有防夾設計、邊角導圓。

填空留給承辦人，因為只有他知道實際需求。

**承辦人做不到的事要標出來**
現場尺寸、專業判斷（哪 12 件、治療師認為需要什麼承重）不能憑空填。列進第伍節，不要假裝規格已經完整。

## 常見紅旗與對應寫法

### 「只有品名沒有規格」

電腦類最嚴重，常只寫「筆電 1 台 教學使用」。完整規格應涵蓋這些面向（以筆電為例）：

| 面向 | 要寫什麼 |
|---|---|
| 處理器 | 世代與等級，並加上跑分門檻（如 PassMark CPU Mark ___ 分以上，以開標當月官網公布分數為準）。只寫「i5 以上」會被舊世代低階品鑽空子 |
| 記憶體 | 容量與規格；插槽數與可擴充上限 |
| 儲存 | 容量與介面 |
| 螢幕 | 尺寸範圍、解析度、面板類型、表面處理 |
| 外接顯示 | 埠別與支援解析度更新率。**要對照本案其他品項**——若同案有大尺寸顯示器，這裡要能接得上 |
| 連接埠 | 逐一列出型別與數量 |
| 無線 | Wi-Fi 與藍牙世代 |
| 視訊音訊 | 鏡頭規格、麥克風、喇叭 |
| 電池電源 | 續航、是否含變壓器 |
| 重量 | 上限 |
| 作業系統 | 版本、語系、授權、是否須可加入網域 |
| 資安 | TPM 等要求 |
| 保固 | 年限、到府或收送、服務窗口與回應時限 |
| 檢驗標章 | BSMI、節能標章 |
| 隨機配件 | 逐項列出 |
| 品況 | 須為原廠全新品，不得為展示機、整新機、拆封品、平行輸入品；提供可於原廠官網查詢之保固序號 |
| 交貨與設定 | 開機設定、與同案設備連線測試、操作說明場次 |

其他設備類（投影機、觸控螢幕、印表機、網通設備）比照這個骨架調整。

### 「數量有單位但無單件尺寸」

「防撞牆墊 200 片」「安全地墊 50 片」——單片 30×30cm 與 60×60cm 差四倍。寫法：

> 必須載明單片尺寸。以 30×30cm 計僅 18 ㎡、以 60×60cm 計為 72 ㎡，兩者相差四倍，現行文件無從核價亦無從驗收。

把兩種算法都算出來給承辦人看，比只說「請補尺寸」有說服力。

### 「1 式」

油漆 1 式、氣密窗 1 式、拆除清運 1 式。要補的是**範圍**：

- 油漆 → 施作面積（牆面 ___ ㎡、天花板 ___ ㎡）、工序（批土幾度、底漆面漆各幾度）、塗料標準與低逸散要求
- 門窗 → 樘數與各樘尺寸（現場丈量）、框材與玻璃規格、性能等級、含拆除清運與收邊
- 拆除清運 → 逐項列出拆除標的與數量、廢棄物合法處理與聯單、圍籬防塵與每日清潔

### 「套組未列內容物」

「科學探究套組（12 件）」→ 應改列 12 件之逐項品名、尺寸與材質，否則不同廠商所報內容無從比較。

### 「尺寸不完整」

「收納櫃 160×120 公分」缺深度。補齊三維，並加上板材、五金、層板載重、防傾倒固定件。

## 安全與法規要求（依標的性質選用）

這些是規格補正表最有價值的部分，因為承辦人通常想不到：

**攀爬、懸吊、攀岩、跳躍類設施**
底板與結構材規格；承重與安全係數；固定方式（化學錨栓）；結構載重確認與安裝簽證；驗收時實施靜載重試驗且費用內含；自由攀爬高度上限與落地區衝擊吸收地墊的範圍；網目尺寸須避開頭頸夾陷區間；扣環須為帶鎖型式。

**軟質與布類**
防焰性能認證標籤（`消防法 §11`）。窗簾、地毯、帳棚、發泡軟包都算。這一項極常漏——文件裡往往只有防撞牆墊要求防焰，窗簾和地墊都沒有。

**兒童使用之教具**
玩具安全國家標準；球徑或零件尺寸須避免誤吞；邊角導圓；甲醛、塑化劑、重金屬含量。

**電器類**
BSMI 商品檢驗標識；配線與裝設由合格電器承裝業施作。若涉及情境燈光，加上演色性與閃爍指數（光敏感學生的考量）。

**板材**
甲醛釋出量分級。用文字寫（F☆☆☆ 級以上），不要寫可能記錯的 CNS 編號。

**窗簾**
不得有垂吊拉繩，或須附安全斷離裝置——纏繞窒息風險。

## 共通條款範本

放在文件第肆節，統一載明可避免逐項重複：

| 項目 | 內容 |
|---|---|
| 全新品 | 所有品項須為全新未使用之正品，不得為展示機、整新品、拆封品或平行輸入品 |
| 同等品 | 本表所列規格為最低要求。廠商得提出同等或優於本規格之產品，並依投標須知規定於使用前檢附廠牌、價格、功能、效益、標準或特性等資料送機關審查 |
| 安全檢驗 | 依品項性質檢附相應之檢驗合格報告與標識 |
| 防焰 | 布類與發泡類材料須檢附防焰性能認證標籤 |
| 安裝安全 | 固定於牆面、天花板或樑之設施須提出結構載重確認及安裝簽證，並於驗收時實施靜載重試驗 |
| 保固 | 設備類、施工類、電腦類分別載明保固年限 |
| 教育訓練 | 交貨後辦理操作與維護說明場次，並提供正體中文操作手冊 |
| 施工時段 | 避開使用時間或以圍籬完全區隔；每日收工後清潔並確保通行安全 |

## 想想有沒有更省事的作法

規格寫得再好，也不如整個繞過去。標案裡若有少量、標準化、市面通行的品項（電腦、事務機、標準家具），值得提醒承辦人：可考慮改由共同供應契約（`採購法 §93`）另案訂購，不併入本標案。

好處是免除規格爭議，有時還能順帶迴避標案裡其他有問題的條款（例如「原產地須屬我國」與筆電的衝突）。若採此作法，估價單要刪除該項並相應調減預算。
