# 五關應檢附文件

只列使用者實際會簽名的五關。開工／估驗／保固另附簡表，供驗收時回頭查。

## 關別判定

| 看到這些文件 | 在哪一關 |
|---|---|
| 需求簽呈、經費核定函、預算書圖、設計圖說、規範 | **需求核定** |
| 投標須知、契約草案、招標公告稿、書圖審查紀錄、監辦通知單 | **發包（公告前）** ← 同時叫 tender-review |
| 開標／比價／議價紀錄、決標紀錄、決標公告、廠商資格查驗 | **決標** |
| 變更原則會勘紀錄、變更設計簽陳、變更前後對照表、議價紀錄 | **變更設計** |
| 竣工報告、初驗紀錄、驗收紀錄、結算明細表、結算驗收證明書 | **驗收** |

判不出來就問，不要猜。承辦常把整案文件塞在一個資料夾裡。

## 一、需求核定

- [ ] 需求簽呈：緣由、經費來源與科目、預估金額、預定期程、採購方式建議
- [ ] 經費核定文件。補助款須附**核定函**：補助比率、自籌款、指定用途、**執行期限**
- [ ] 採購標的性質判定說明（工程／財物／勞務，見 `nature-test.md`）
- [ ] 設計圖說（平面、剖面、細部、施工大樣）
- [ ] 施工規範或技術規格
- [ ] **採購預算書（詳細價目表）**，含**單價分析**
- [ ] 請照必要性評估（建築法上屬何種建造行為，見 `parallel-duties.md`）
- [ ] 建築師或技師簽證文件（如屬應簽證範圍）

**預算書必查有無編列**（採購規範三(七)、品管要點十三）：

| 項目 | 依據 | 漏了會怎樣 |
|---|---|---|
| **品管費用** | 品管要點十三；間接工程費依《新北市政府所屬各機關間接工程費用編列原則》 | 廠商無從執行品管 |
| **材料設備抽驗費用（單獨量化）** | 品管要點十三 | 檢驗做不了，驗收無依據 |
| **工程管理費** | 《新北市政府所屬機關工程管理費及工作費編列支用要點》 | 250 萬以上另須提列 25% 存專戶 |
| 勞工安全衛生費 | 營造安全衛生設施標準 | 廠商不會搭護欄 |
| **圍籬綠美化**（公告金額以上須架圍籬者） | 採購規範三(五) | 市府明定由主辦機關編列 |
| 空氣污染防制費 | 營建工程空污費費率；注意收費辦法 §21 免繳 | 事後補繳 |
| 保險費（覈實編列） | 採購規範三(六) | 契約要求投保但沒錢 |
| 廢棄物與剩餘土石方清運 | 依規模 | 老校舍拆除案最常漏 |
| 營業稅、利潤與管理費 | | 直接用廠商報價當預算 |

節能減碳經費（採購規範三(十一)）：**整修、維護、拆除、疏濬、結構補強、開口契約免除**
——學校修繕案多半落在免除範圍，不必強求。

**沒有單價分析的預算書是後段爭議的源頭。** 變更設計新增項目時，
採購規範二五(一)1(5) 要求「以原預算相關單價分析資料為基礎」——沒有分析資料就只能任廠商開價。

**只有平面圖沒有細部大樣**＝把設計責任推給廠商，驗收時沒有可比對的基準。

## 二、發包（公告前）

齊備性看本清單；**合法性交給 `tender-review`**，不要重複。

- [ ] 簽陳（招標方式、決標原則、預算金額、廠商資格、期程）
- [ ] **招標文件書圖審查紀錄** ← 150 萬以上須第二級（見下）
- [ ] 投標須知
- [ ] **契約：新北市政府工程採購契約範本（115年5月版）**，非工程會版
- [ ] 投標廠商聲明書、投標標價清單（工程採購用）
- [ ] 需求說明書／施工規範／設計圖說
- [ ] 廠商資格文件要求（營造業登記證與**承攬造價限額**、室內裝修業、專業工程能力、實績）
- [ ] 監辦通知單
- [ ] 洽採購處代辦與否之簽核（150 萬～5,000 萬，首長核准事項）

**書圖審查是這一關的核心**（採購規範第五點）。150 萬以上工程，學校因無工程技術職系人員
而落入但書，須準用第二級：

- [ ] 中階以上主官（管）擔任召集人
- [ ] **審查委員至少 2 人，且非本校人員**（五(九)）
- [ ] 委員符合五(八)所列 13 類資格之一
- [ ] 委員**具結**（附件一）
- [ ] 招標文件**載明**委員不得投標、作為分包廠商或擔任投標廠商工作成員（五(二)）
- [ ] 審查方式為審查會議／書面審查／併行（五(十)），**不能只用公文逐級陳核**
- [ ] 審查內容涵蓋：邀標書、投標須知、契約書樣稿、採購預算書（五(六)）
- [ ] 建築類另參附件三；非建築類參附件四

**廠商資格是工程案的分水嶺。** 只寫「合法登記之廠商」等於沒有要求。
營繕工程須營造業登記（綜合／專業／土木包工業各有承攬造價限額與地域限制）；
室內裝修須內政部登記之室內裝修業。

## 三、決標

- [ ] 開標／比價／議價紀錄
- [ ] 決標紀錄、決標公告（決標日起 30 日內依 §61／§62 辦理，採購規範二二）
- [ ] **廠商資格文件實際查驗紀錄**（營造業登記證有效期與承攬限額、拒絕往來廠商查詢列印）
- [ ] 標價偏低處理紀錄（如有）
- [ ] 契約用印簽核
- [ ] 撥款作業：**未達 250 萬決標後製據**／**250 萬以上簽約後製據**（採購規範二四(一)）

## 四、變更設計

**兩階段，不能跳**（採購規範第二十五點）。

**階段一：書面確認變更原則**（附件六）
- [ ] 原採購標的（設計）內容
- [ ] 變更事由（可歸責機關／廠商／不可抗力）
- [ ] 變更內容概述與範圍
- [ ] 變更所需經費概估；新增非原數量清單項目者，
      **單價以原預算單價分析為基礎並考慮市場價格波動**
- [ ] 須其他單位配合者之配合事項
- [ ] **載明本變更原則應經機關通知後始得據以辦理**

**階段二：審查與核准**
- [ ] 審查變更原則及個別變更事由（附件八、附件九）
- [ ] **報請首長或授權人員簽報核准後**，才通知廠商辦理變更圖說（附件七）
- [ ] 依第五點完成變更圖說及書圖審查，作成紀錄，修正預算書圖，再簽請核准（附件十）
- [ ] 洽廠商**議價**（除得以換文方式者外）
- [ ] 追加預算須本府補助者：**不論金額多寡皆報經本府核准**，並釐清責任歸屬
- [ ] 決標金額增加者依 §61／§62 辦理
- [ ] 工期展延評估
- [ ] 當次變更減帳絕對值＋加帳達 2,500 萬以上者，依原審查方式再審查（五(四)）

**先核定後施工。** 已施工才補辦變更，該部分可能無法核銷。

## 五、驗收

- [ ] **採購履約完成確認表**（竣工日前或當日，會同監造與廠商核對項目數量）
- [ ] 材料、設備進口／出廠證明
- [ ] 材料、設備檢、試驗紀錄（150 萬以上須 CNS 17025 認證實驗室）
- [ ] 查驗紀錄
- [ ] 結算明細表
- [ ] 竣工圖（須反映實際施工，不是設計圖改標題）
- [ ] 設備類：運轉試車、絕緣測試、安全檢查報告、敷管敷線、水（氣）壓試驗、
      接地電阻、管路沖洗紀錄表、零件型錄圖、維護操作手冊
- [ ] 初驗紀錄、複驗紀錄
- [ ] **協驗**：初驗合格後預定驗收日 10 日前函報教育局（綠化植栽達公告金額報農業局）
- [ ] **主驗人指派**：承辦採購單位之人員**不得**為主驗人或材料檢驗人（二六(八)）
- [ ] 會驗人由**使用或接管單位**派員（二六(十)）
- [ ] 驗收缺失改善通知與複驗紀錄（成對）
- [ ] 逾期違約金計算表（如有逾期）
- [ ] 減價收受簽核（如有）
- [ ] **工程結算驗收證明書**
- [ ] 建築工程參附件十一驗收項目表
- [ ] 結算資料驗收後 20 日內填報工程會系統
- [ ] **履約計分**填報公共工程標案管理系統（採購規範三十）
- [ ] 保留款結清（驗收合格、完成結算、繳結保固保證金及扣罰款後）
- [ ] **財產增值或新增財產登帳**

「承辦採購單位之人員」指該案**最基層承辦人員**，**不以總務、庶務人員為限**。
總務主任既是承辦又當主驗，是學校最常見的程序瑕疵。

## 附：三關簡表（通常不上到校長，但驗收時要回頭查）

### 開工——漏最多，且驗收時補不回來

履約保證金／開工報告／施工計畫／**品質計畫（經核定）**／**監造計畫（經核定，含自辦監造）**／
**監造計畫外聘專家審查意見表與逐項修正確認**／勞安管理計畫／**職安法 §26 書面告知（開工前、留簽收）**／
保險單（生效日不晚於開工日）／建照或雜項執照／室內裝修審查許可／道路挖掘許可／
工程會系統開工填報／預定進度表（S 曲線）

**核定紀錄比計畫本身重要。** 收到計畫沒核定，等於默示接受了一份沒看過的文件。

### 施工與估驗計價

施工日誌（連續逐日、簽章、實際出工與施工項目）／監造報表／材料設備送審與核可／
檢驗報告（CNS 17025 標誌）／自主檢查表／檢驗停留點查驗／**隱蔽部分覆蓋前查驗與照片**／
施工前中後照片（同角度）／估驗計價單＋明細＋**監造核符簽認**／保留款扣留／
進度落後通知／缺失改善與複查／**主管每月・承辦每週工地督導紀錄（附件五）**／
**進度達 90% 之圖面數量清查**

估驗計價要對三件事：數量對得上施工日誌、對得上照片、累計不超過契約與預定進度。

### 保固

保固保證金／保固期間（結構體與非結構體不同，起算日以驗收合格日為準）／保固切結書／
保固期內缺失通知與改善／期滿查驗與保證金退還簽核／操作維護手冊與備品移交
